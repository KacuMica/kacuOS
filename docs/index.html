What this actually is

kacuOS is an Arch-based distribution with no desktop environment by default — just a shell, a minimal set of tools, and kacuctl, a small Rust CLI that installs curated package bundles and lets you extend the system with sandboxed Lua plugins.

Arch already gives you full control over what's installed. kacuOS just starts from a smaller default and gets out of your way after that — no compositor by default, no GUI installer, no bundled apps you didn't ask for.

you@kacu kacuctl list

Presets, not a fixed install

Every preset is a plain TOML file you can read before you run it — a name, a package list, an optional setup script. No opaque installer scripts.

devtoolsgcc, cargo, make, cmake — build essentials

clusterDocker + k3s, traefik/servicelb/metrics-server disabled by default

Built around a RAM budget

zram is on by default. Optional presets stay optional — a fresh Server install has no browser, no compiler, no container runtime until you ask for one.

Server profile

Headless base: shell, git, an editor, nothing graphical.

Desktop profile

Adds sway as a minimal compositor — just enough to open one app window, not a full DE.

kacu-sysinfo

A small C utility that reads RAM/CPU/load straight from /proc — no shelling out to heavier tools.

Rolling release

Arch underneath — pacman, AUR-compatible, no version lock-in.

Plugins ask before they act

Plugins are Lua, run in a sandbox. A manifest declares what a plugin is allowed to do — and kacuctl shows you that request before it installs anything.

[permissions]
exec = false  -- most plugins never need this
hooks = ["shell_prompt"]

-- init.lua
kacu_hooks["shell_prompt"] = function()
  local branch = kacu.exec_readonly("git branch --show-current")
  kacu.print("branch: " .. branch)
end
