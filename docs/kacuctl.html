A preset + plugin manager,
not tied to one distro.

kacuctl started as kacuOS's own package tool. It's grown into something you can run on its own — install curated package bundles from plain TOML files, extend it with sandboxed Lua plugins, on whatever Linux you're already running.

Platform support

Today kacuctl assumes pacman (Arch and Arch-based systems). Per-OS package manager backends are planned — each will ship as its own small adapter, same TOML preset format on top.

Arch / pacman
available now
Debian / apt
planned
Fedora / dnf
planned

Why Rust

kacuctl runs Lua plugins from third parties. A memory-safety bug in the part of the code that sandboxes someone else's code is the worst place to have one — Rust's ownership model rules out a whole category of that risk at compile time, not by convention.

Try it

# any existing Arch install, no ISO needed
git clone https://github.com/kacu-os/kacuOS.git
cd kacu/kacuctl
cargo build --release
sudo cp target/release/kacuctl /usr/local/bin/

kacuctl list
kacuctl status
